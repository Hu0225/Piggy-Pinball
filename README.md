# 好运弹珠社 · PIGGY PINBALL

根据参考图制作的复古小猪街机弹珠小游戏，使用原生 HTML、CSS 和 Canvas，无需安装依赖。

## 在线游玩

打开 [好运弹珠社](https://hu0225.github.io/Piggy-Pinball/) 即可直接游玩，支持电脑和手机。

## 直接游玩

双击 `好运弹珠社.html`，即可在现代浏览器中离线游玩。所有样式、绘图、音效和物理代码均内嵌在这一个 HTML 文件中。

- 初始有 990 颗游戏弹珠。投入至少 1 颗即可激活游戏，每次投入即时扣除余额，每局总本金最多 99 颗。
- 激活后点击“确定倍率”，随机抽取 2–12 倍。确定倍率后、发射前仍可继续加注，所有投入都计入本局本金，倍率和亮灯轨道保持不变。低倍率亮灯轨道更多：2 倍有 6 条，3 倍有 5 条，4–5 倍有 4 条，6–7 倍有 3 条，8–10 倍有 2 条，11–12 倍有 1 条。
- 每局仅发射 1 颗判定珠，决定全部本金的结果。向下拉动拉杆、松手发射；也可按住空格键、橙色按钮或台面蓄力。发射后锁定本金，不能再加注或发射。
- 判定珠落入亮灯轨道时，返还“总本金 × 本局倍率”颗弹珠，返珠已包含本金；未亮灯轨道不返珠。例如先投入 5 颗、确定 6 倍后再加注 5 颗，总本金为 10 颗，命中返还 60 颗并获得 2 张积分卡。
- 本局中奖返珠每满 30 颗得 1 张积分卡，30 / 60 / 90 颗对应 1 / 2 / 3 张，无 3 张上限；余数不跨局累计。积分卡在整局结算时一次发放。
- 积分卡可在礼品柜兑换游戏内的小猪贴纸、好运挂件、小猪公仔和奖杯，分别需要 1 / 3 / 6 / 12 张卡。余额和藏品保存在当前浏览器。
- 发射前可取消本局，退回全部本金。刷新页面时保留已结算奖励，未结算回合退回全部本金。旧版本存档会保留余额和藏品，并按旧规则处理尚未结束的回合。
- 弹珠余额为 0 且没有进行中的回合时，可领取 50 颗补给继续游玩。
- 台面在倍率确定后显示“命中可返”的本金 × 倍率数值，加注时同步更新；落袋结算后改为显示“本局返珠”的实际结果。
- 按 M 或右上角喇叭开关音效。手机端使用无滚动的单屏布局：余额、台面和底部拉杆同屏显示，投珠与加注在弹窗内完成，点击“？”翻页查看玩法。页面根据可视高度和安全区适配较短的 WebView，调节数量时不会弹出手机键盘。

## 修改源码

`dist/index.html` 是页面结构，`dist/style.css` 是响应式外观，`dist/app.js` 是绘图和交互，`dist/physics.js` 是独立物理引擎，`dist/rules.js` 管理回合、返珠、积分卡与兑换。没有第三方图片、字体、脚本或网络请求。

修改后运行 `node build-single.mjs`，重新生成单文件 HTML。

## 本地预览与验证

在本目录运行 `python -m http.server 4173 --directory dist`，浏览器访问 http://localhost:4173 。

运行 `node test-physics.cjs` 验证 101 档力度、所有奖励槽及物理引擎的 10 球并发能力；实际玩法每局仅发射一次。

运行 `node test-rules.cjs` 验证投珠激活、倍率锁定、发射前加注、单次发射限制、总本金结算、积分卡阈值、礼品兑换和新旧存档恢复。

## GitHub Pages 部署

`.github/workflows/pages.yml` 会在 `main` 分支的游戏文件发生变化时，检查脚本、运行物理测试，并将 `dist/` 发布到 GitHub Pages。也可以在 GitHub 的 Actions 页面手动运行 “Deploy game to GitHub Pages”。

仓库 Settings → Pages 的发布来源使用 **GitHub Actions**。

这是使用虚拟弹珠的休闲积分游戏，不包含充值、现金或实物兑换。
